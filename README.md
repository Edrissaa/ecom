# Soleva — premium sneaker storefront

An editorial, conversion-focused ecommerce homepage for a fictional sneaker brand, built with
**Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Lucide**.

The desktop layout follows the supplied reference — hero, three promo cards, a 3 × 2 product grid,
an editorial mosaic, a second grid, a campaign banner and a dark footer — with original branding,
copy and artwork. Tablet and mobile are redesigned, not scaled down.

```bash
npm install
npm run dev          # http://localhost:3000
npm run build && npm start
npm run lint
npm run typecheck
```

Node 20.9+ is required (Next 16).

## What's in the box

| Area | Details |
| --- | --- |
| **Homepage** | Header → hero carousel → 3 promo cards → *Newly Dropped* → *Most Recommended* mosaic → *Summer* → campaign banner → footer |
| **Cart** | Add / increment / decrement / remove, subtotal, free-shipping meter, drawer **and** `/cart` page. Persisted in `localStorage`, synced across tabs, tolerant of corrupt data |
| **Buy Now** | Adds the pair and opens the bag with *Checkout* one click away |
| **Search** | Debounced overlay filtering name, category, colour and description; add-to-bag from results |
| **Wishlist** | Heart toggle on every card, header count, `/wishlist` page |
| **Navigation** | Desktop nav with animated underline, mobile drawer, working `/shop/*` and `/help/*` pages so no link is dead |
| **Checkout** | `/checkout` demo — see *Before you ship* |

### Accessibility
Semantic landmarks and a single `<h1>` per page, skip link, visible focus rings (light on dark surfaces),
labelled icon buttons, 44 px touch targets, `aria-live` cart announcements, and a shared dialog hook that gives
every overlay **Escape to close, a Tab focus-trap, scroll lock and focus restoration**. Closed overlays are `inert`.
The hero carousel has pause/play, `aria-roledescription` slides and is reduced-motion aware; all animation
respects `prefers-reduced-motion`.

### Performance
Server Components by default (client components only where state is needed), static prerendering for every
route, self-hosted variable fonts via `next/font`, `next/image` with AVIF/WebP, intrinsic sizes + blur placeholders
from static imports, `preload` only on the first hero slide, no animation library.

## Project structure

```
src/
  app/                 routes: / · /shop/[slug] · /help/[slug] · /cart · /checkout · /wishlist · 404
  components/
    home/              HeroSection · EditorialCards · ProductSection · CollectionMosaic · LifestyleBanner
    product/           ProductCard · ProductGrid · ProductActions · WishlistButton
    cart/              CartDrawer · CartLineItem · CartView · CheckoutView · OrderSummary
    layout/            Header · MobileMenu · SearchOverlay · Footer · Newsletter · PageIntro
    ui/                Button · Badge · Drawer · Logo · QuantityStepper · Reveal · SectionHeading
    providers/         ShopProvider (cart · overlays · wishlist)
  data/                products · images · home (hero/promo/mosaic copy) · navigation · collections · help · site
  hooks/               use-dialog · use-debounced-value
  lib/                 persistent-store · cart-store · wishlist-store · format · cn
  assets/images/       generated artwork (see below)
scripts/generate-images/   the artwork generator
```

Product cards are rendered by mapping over `src/data/products.ts`; everything on the homepage that is copy or
imagery is data in `src/data/`.

## Design tokens

Defined once in `src/app/globals.css` (`@theme`): ivory `#F7F4EF`, sand `#EFEAE2`, espresso `#21170F`,
footer `#1D130D`, walnut `#765234`, caramel `#986C42`, beige `#D9CDBF`, line `#E6DED4`, muted `#70685F`.
Headings use Playfair Display, UI text uses Manrope. Caramel is decorative only — it does not meet contrast for body text.

## Imagery: read this before launch

No photo service is reachable from the build sandbox, and hot-linking unverified URLs risks broken images, so
**all pictures are original illustrations generated by code** (`npm run generate:images`): three parametric
sneaker silhouettes, twelve colourways, and eleven staged still-life scenes with film grain. They are stand-ins
for photography, not a substitute for it.

To use real photos, overwrite the files in `src/assets/images/**` with images of the **same aspect ratio**
(see `src/data/images.ts` for the full registry and alt text). Nothing else changes — Next derives
dimensions and blur placeholders from the files. For a CDN instead, point a registry entry at a URL and add
the host to `images.remotePatterns` in `next.config.ts`.

| Slot | Ratio | Size used |
| --- | --- | --- |
| `hero/*` | 2 : 1 | 2000 × 1000 (subject right of centre; per-slide crop in `data/home.ts`) |
| `promo/*` | 4 : 5 | 840 × 1050 |
| `mosaic/mosaic-tall` | ≈ 3 : 4 | 960 × 1240 |
| `mosaic/mosaic-top`, `mosaic-bottom` | 3 : 2 | 1200 × 800 |
| `mosaic/mosaic-wide` | ≈ 2.7 : 1 | 2400 × 900 |
| `banner/banner-cta` | 3 : 1 | 2400 × 800 (subjects at both edges, calm centre for the headline) |
| `products/*` | 4 : 3 | 1200 × 900, pale neutral background |

## Before you ship

These are deliberately front-end only and need real wiring:

- **Newsletter** validates and confirms locally; it does not send the address anywhere (`components/layout/Newsletter.tsx`).
- **Checkout** is a demo: it collects delivery details, confirms an order on screen and clears the bag. It collects **no payment
  details** and creates no order. Replace `handleSubmit` in `components/cart/CheckoutView.tsx` with your provider's hosted checkout.
- **Policy pages** (`data/help.ts`) are sample copy. Have them reviewed.
- **Social links** (`data/navigation.ts`) point at each network's home page — swap in the brand's profiles.
- **Account icon** links to *Track order* since there is no sign-in in this build.
- Set `NEXT_PUBLIC_SITE_URL` (see `.env.example`) so canonical URLs, Open Graph and the sitemap use your domain.
- `npm audit` reports advisories in dev-only tooling (`eslint-config-next`'s glob dependencies); none ship to the browser.
